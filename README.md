# Generador de Informe ASG/ESG

Genera un informe de sostenibilidad ASG/ESG para pymes con referencias a GRI 2021, CSRD y la Agenda 2030, y lo descarga como documento Word (.docx). El documento se construye entero en el navegador.

Es software libre. Los datos que se escriben en la herramienta se procesan en el navegador y no se envían a ningún servidor.

**Versión en línea:** https://yel-martinez-portfolio.com/recursos/generador-de-informe-asg-esg-gratuito-para-pymes/

## Uso

Abre `index.html` en un navegador. No hace falta servidor ni instalación.

Archivos:

- `index.html`: la herramienta, como página independiente.
- `script.js`: la lógica (todo está dentro del espacio de nombres de la herramienta para no chocar con otro código).
- `style.css`: los estilos (acotados al contenedor de la herramienta).

## Dependencias

- [JSZip 3.10.1](https://stuk.github.io/jszip/) (licencia MIT o GPL-3.0), cargada desde cdnjs en `index.html`, para construir el archivo .docx. No se incluye en este repositorio.
